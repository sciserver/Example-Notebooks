<h2>Welcome to SciServer's <a href='https://github.com/sciserver/Example-Notebooks'>Example Notebooks</a> for Compute!</h2>

<p>This directory contains example notebooks that can help you start using SciServer for your data science and science education projects. Use these to learn Python syntax, and as templates for creating your own notebooks.</p>

<p>You should be looking at this document in your persistent folder, after copying the example notebooks from the Getting Started data volume or cloning them from our GitHub repository. You can now save any of these notebooks in a SciServer container and adapt them to your needs.</p>

<p>The welcome.ipynb notebook gives you a quick introduction to working with SciServer

<h3>Index</h3>

<p>In addition to the welcome example, this directory contains folders with additional example notebooks. Here is a list of what is available. Look at the readme file in each folder to learn what example notebooks are available.</p>

<ul>
    <li>astronomy: astronomy examples from the Sloan Digital Sky Survey and other projects, including classroom and lab activities</li>
    <li>baseball: examples using the history of plays in Major League Baseball (from retrosheet.org)</li>
    <li>biomed: working with the AstroPath pathology project</li>
    <li>components: guides to using the components of SciServer, such as the CasJobs database access tools</li>
    <li>data-science-education: classroom activities for teaching data science courses</li>
    <li>materials-science: working with NIST's AMBench additive manufacturing project</li>
</ul>
